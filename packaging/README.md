# Packaging

This directory contains installer and distribution package metadata for TabSSH Desktop.

Platform packages are built from the release binaries in CI.

## Planned packages

- `.deb` (Debian/Ubuntu) — packaging metadata and scripts
- `.rpm` (RHEL/Fedora) — spec files
- AUR PKGBUILD (Arch Linux)
- AppImage — AppDir structure
- `.dmg` (macOS) — app bundle and DMG layout
- Homebrew formula
- MSI (Windows) — WiX configuration
- WinGet manifest
- Scoop manifest (Windows)
- FreeBSD ports
- OpenBSD packages
- NetBSD pkgsrc
